## 进行中：jar 聚合源解封（MITM 代理）

**已验证**：MITM 启动 ✓、ProxySelector 拦截生效 ✓（日志 "no key manager for p.bfvp26.com" = jar/应用流量已进来）、CA 已生成并导出 ✓（files/mitm_ca.crt 727B + key 1219B）
